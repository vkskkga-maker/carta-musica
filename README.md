# 💌 Carta Música

Uma página web interativa criada para transformar uma mensagem especial em uma experiência digital personalizada.

A **Carta Música** permite criar uma carta virtual combinando texto, imagens e música em uma experiência pensada para momentos especiais, como declarações, aniversários, datas comemorativas ou simplesmente para demonstrar carinho.

## Funcionalidades

* Carta digital personalizada
* Possibilidade de adicionar fotos
* Música integrada à experiência
* Mensagem personalizada
* Experiência diretamente pelo navegador
* Compatibilidade com dispositivos móveis

## 🛠️ Tecnologias

O projeto foi desenvolvido utilizando:

* HTML5
* CSS3
* JavaScript
* Git
* GitHub
* GitHub Pages

## 🎯 Objetivo

O objetivo do projeto é criar uma forma simples e criativa de transformar uma mensagem em uma experiência digital.

A pessoa pode personalizar a carta e compartilhar o resultado com alguém especial.
